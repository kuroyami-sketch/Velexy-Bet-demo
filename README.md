# Velyx Bet — Demo V1

Protótipo local de cassino demonstrativo com **K Coin (KC)**, sem dinheiro real.

## Recursos
- Home responsiva
- Cassino com 8 jogos demo
- Crash, Mines, Roleta, Dice, Blackjack, Tiger Fortune, Crossy Road e Plinko
- Carteira de K Coin persistida em localStorage
- Pix, cartão e boleto apenas como simulações de crédito fictício
- Caminho visual de dinheiro real explicitamente desativado
- Histórico de apostas e créditos
- Métricas do perfil
- Layout responsivo desktop/mobile

## Rodar
Não há dependências.

Opção simples:
```bash
python3 -m http.server 8080
```
Depois abra `http://localhost:8080`.

## Importante
Este projeto é uma demonstração técnica. Não processa pagamentos, não recebe depósitos, não permite saques e não concede prêmios em dinheiro ou itens convertíveis em dinheiro.
